# Ruta de aprendizaje: Data Visualization

El programa de Data Visualization forma especialistas en la comunicación efectiva de datos a través de visualizaciones impactantes. Los estudiantes desarrollarán habilidades técnicas y de diseño para crear dashboards y reportes interactivos.

## Datos del programa

- Duración: 4 meses
- Modalidad: Virtual y Presencial
- Nivel: Básico a Intermedio

## Cursos del programa

1. **Fundamentos de Visualización de Datos**: Curso introductorio sobre principios de visualización efectiva.
2. **Tableau Desktop Avanzado**: Formación completa en Tableau Desktop desde nivel básico hasta avanzado.
3. **Power BI y Microsoft Stack**: Curso especializado en Power BI y el ecosistema Microsoft para analytics.
4. **Python para Visualización**: Formación en bibliotecas de Python para visualización como Matplotlib, Seaborn y Plotly.
5. **D3.js y Visualizaciones Web**: Curso avanzado en D3.js para crear visualizaciones web personalizadas.
6. **Dashboards Ejecutivos y Storytelling**: Formación especializada en diseño de dashboards para alta gerencia.

## Cómo orientar al alumno

- Antes de recomendar, pregunta por su experiencia previa y su objetivo profesional.
- Para precios, fechas de inicio, becas o requisitos de admisión no respondas de memoria: usa `retrieve_documents`.
- Si la persona quiere avanzar con el programa, ofrécele `solicitar_asesoria`. Esa acción solo se ejecuta con su confirmación explícita.
