# Ruta de aprendizaje: Data Architect

El programa de Data Architect forma especialistas en el diseño de arquitecturas de datos empresariales. Los participantes desarrollarán habilidades para crear estrategias de datos, gobiernos de información y arquitecturas técnicas escalables.

## Datos del programa

- Duración: 5 meses
- Modalidad: Virtual y Presencial
- Nivel: Avanzado

## Cursos del programa

1. **Arquitectura de Datos Empresarial**: Curso fundamental sobre principios de arquitectura de datos a nivel empresarial.
2. **Data Modeling y Diseño de Esquemas**: Formación especializada en modelado de datos para diferentes contextos.
3. **Cloud Architecture para Datos**: Curso avanzado sobre arquitecturas de datos en la nube usando AWS, Azure y GCP.
4. **Gobierno de Datos y Calidad**: Formación integral en estrategias de gobierno de datos y calidad de información.
5. **Data Mesh y Arquitecturas Modernas**: Curso especializado en arquitecturas emergentes como Data Mesh y Data Fabric.

## Cómo orientar al alumno

- Antes de recomendar, pregunta por su experiencia previa y su objetivo profesional.
- Para precios, fechas de inicio, becas o requisitos de admisión no respondas de memoria: usa `retrieve_documents`.
- Si la persona quiere avanzar con el programa, ofrécele `solicitar_asesoria`. Esa acción solo se ejecuta con su confirmación explícita.
