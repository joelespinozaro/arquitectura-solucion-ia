# Ruta de aprendizaje: Data Engineer

El programa de Data Engineer está diseñado para formar profesionales capaces de diseñar, construir y mantener sistemas de datos a gran escala. Los estudiantes aprenderán a trabajar con tecnologías modernas de big data, pipelines de datos y arquitecturas distribuidas.

## Datos del programa

- Duración: 6 meses
- Modalidad: Virtual y Presencial
- Nivel: Intermedio a Avanzado

## Cursos del programa

1. **Fundamentos de Python para Data Engineering**: Este curso introduce los conceptos básicos de Python enfocados en el manejo de datos.
2. **Apache Airflow y Orquestación de Datos**: Curso especializado en Apache Airflow para la creación y gestión de pipelines de datos.
3. **AWS para Data Engineers**: Formación integral en servicios de Amazon Web Services orientados a ingeniería de datos.
4. **Docker y Kubernetes para Datos**: Curso práctico sobre containerización y orquestación de aplicaciones de datos.
5. **Apache Spark y Big Data Processing**: Formación avanzada en Apache Spark para el procesamiento de grandes volúmenes de datos.
6. **Bases de Datos NoSQL**: Curso especializado en bases de datos no relacionales incluyendo MongoDB, Cassandra y Redis.

## Cómo orientar al alumno

- Antes de recomendar, pregunta por su experiencia previa y su objetivo profesional.
- Para precios, fechas de inicio, becas o requisitos de admisión no respondas de memoria: usa `retrieve_documents`.
- Si la persona quiere avanzar con el programa, ofrécele `solicitar_asesoria`. Esa acción solo se ejecuta con su confirmación explícita.
